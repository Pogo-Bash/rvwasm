# The domains the machine may reach through the public relay (docker/net-allowlist.sh, docs/deploy.md).
#
# One domain per line; a domain also allows its subdomains (github.com includes api.github.com). Lines starting
# with # and empty lines are ignored. The relay's DNS server answers for these names only, and the firewall lets the
# machine connect, on TCP ports 80 and 443 only, to the addresses those answers had.
#
# After editing:   docker compose exec relay /opt/rvwasm/allowlist-reload.sh      (no restart; machines stay up)
